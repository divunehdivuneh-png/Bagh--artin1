باغ آرتین — نسخه ارتقایافته

نصب: فایل index.html را جایگزین index.html مخزن فعلی GitHub کنید و Commit کنید. برای حفظ اطلاعات قبلی، ابتدا از برنامه قدیمی فایل JSON بگیرید؛ نسخه جدید همان ساختار پشتیبان را بازیابی می‌کند.

افزوده‌ها: ذخیره‌سازی IndexedDB با مهاجرت داده‌های LocalStorage، ثبت مدت عملیات/آبیاری، گزارش بازه شمسی و نوع عملیات و قطعه، خلاصه هزینه و برداشت و عملکرد درختان، خروجی CSV سازگار با Excel، پشتیبان JSON.

محدودیت‌ها:
- IndexedDB داده را روی همان دستگاه و مرورگر نگه می‌دارد؛ پاک‌کردن داده‌های Safari یا تعویض گوشی ممکن است آن را حذف کند. این نسخه همگام‌سازی ابری ندارد.
- همگام‌سازی چنددستگاهی به backend و احراز هویت نیاز دارد و بدون تنظیمات/کلیدهای سرویس فعال نشده است.
- تشخیص گفتار فارسی در Safari به پشتیبانی نسخه iOS و اجازه میکروفون وابسته است؛ در صورت عدم پشتیبانی از میکروفون صفحه‌کلید استفاده کنید.
- خروجی CSV با UTF-8 BOM در Excel باز می‌شود، اما XLSX بومی نیست.
- آزمون واقعی روی آیفون و مخزن GitHub شما از این محیط ممکن نیست.

اصلاحات نسخه جدید:
- تاریخ شمسی هم با ۸ رقم پیوسته (مثل ۱۴۰۵۰۸۰۹) و هم با جداکننده پذیرفته می‌شود؛ جداکننده‌ها هنگام تایپ خودکار درج می‌شوند.
- متن حاصل از دیکته صوتی صفحه‌کلید آیفون هنگام ورود، برای پرکردن خودکار فیلدهای عملیات/برداشت پردازش می‌شود.
- دکمه ضبط مستقیم فقط در مرورگرهایی کار می‌کند که SpeechRecognition را پشتیبانی کنند؛ Safari آیفون ممکن است آن را پشتیبانی نکند. فعال‌سازی ضبط مستقل و مطمئن در همه دستگاه‌ها نیازمند سرویس پشتیبان امن است و در این بسته ادعا نمی‌شود که فعال شده است.
- ساختار پایگاه داده و کلیدهای ذخیره‌سازی تغییر نکرده‌اند تا داده‌های قبلی روی همان دستگاه حفظ شوند؛ با این حال پیش از جایگزینی نسخه، از بخش پشتیبان‌گیری خروجی JSON بگیرید.
